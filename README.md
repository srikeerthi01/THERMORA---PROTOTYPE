# THERMORA — Urban Heat Intelligence Prototype

A frontend-only, responsive React + Vite prototype built from the supplied brief.

## Run locally

1. Install Node.js (18+ recommended).
2. Extract this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Included
- Landing page, Heat Explorer, AI Insights, Mitigation Lab, Impact Dashboard
- Burgundy / blush / chartreuse design system
- Simulated Hyderabad hotspot map and demo data
- Interactive hotspot selection, search, map layers and zoom controls
- Simulated AI analysis with animated wave-dot loader
- Selectable cooling recommendations
- Dynamic mitigation sliders, shade toggle and before/after comparison
- Recharts dashboard visualizations and demo report interaction
- Responsive mobile navigation and reduced-motion support

All city measurements, AI output, map features and scenario results are illustrative demo content. There is no backend, authentication, live sensor feed, satellite processing, API integration or real AI model.
